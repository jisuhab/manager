프로젝트 포팅

기존 프로젝트의 화면/관리 항목 구조만 재사용하고 고객 고유 데이터는 초기화한 뒤, 각 메뉴에 작성 방법을 알 수 있는 예시 데이터를 제공합니다. 포팅 CSV는 프로젝트 정보, 제안 개요, Scope, 일감, 장비 인벤토리, 고객 준비사항, 변경 이력, 구축 진행률을 한 파일로 관리합니다. 드롭다운 항목은 CSV의 '선택 가능 값 안내' 컬럼에서 입력 가능한 값을 확인할 수 있습니다. 템플릿의 [예시] 값은 실제 고객 정보로 교체하거나 삭제해서 사용하세요. 수정 본 저장 시 현재 프로젝트 데이터만 HTML에 포함되도록 과거 고객용 기본 데이터는 정리됩니다. 네트워크 구성도 이미지는 CSV에 포함되지 않으므로 화면에서 별도 등록합니다.
권장 순서: 신규 프로젝트 템플릿 적용 → 예시 데이터 확인/교체 → 포팅 CSV Export → Excel에서 신규 고객 정보 작성 → 포팅 CSV Import → 수정 본 저장

수정 본 저장

저장 방식을 선택하세요. 두 방식 모두 현재 화면의 편집값과 버전 이력을 HTML에 포함합니다. 저장된 HTML을 다시 열면 파일에 포함된 저장 시점 데이터를 기준으로 시작합니다.
